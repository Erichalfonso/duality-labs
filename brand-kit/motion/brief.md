# Duality Labs — Motion Brief

## Visual Reference / Aesthetic Target

Cinematic tech product reveals. Key references:
- Anthropic Claude launch videos — slow fade-ins from black, glowing gradients, text that materializes
- Linear product videos — smooth kinetic typography, dark UI floating in space
- Vercel feature drops — minimal, fast cuts, code/data elements as visual language
- Stripe product demos — clinical precision, stats that count up, clean motion paths

**Feeling to hit:** expensive, quiet confidence. Not flashy. The motion should feel like the product itself — precise, intelligent, intentional.

## Brand Tokens for Motion

### Colors
| Token | Hex | Use in motion |
|---|---|---|
| Background | `#0A0A0A` (near-black) | Scene base — pure dark |
| Accent | `#0066FF` | Glow, highlight, reveal color |
| Accent gradient | `#0066FF → #0052CC` | Gradient wipes, light rays |
| Text | `#FFFFFF` | Primary type |
| Text secondary | `#737373` | Supporting labels, eyebrows |
| Border/subtle | `#1A1A1A` | Card edges, dividers |

> Use the dark color palette (inverted from the website's light theme). Motion lives on near-black.

### Typography
| Role | Font | Weight | Style |
|---|---|---|---|
| Headlines | Inter | 500 | Tight tracking, large |
| Eyebrow labels | JetBrains Mono | 400 | 12px, uppercase, letter-spacing widest |
| Stats/metrics | Inter | 600 | Mono-tabular, accent color |
| Body copy | Inter | 400 | Secondary color |

### Symbol
- **Ψ** — Georgia serif, weight 700
- Use as: logo reveal anchor, watermark element, transition device
- Accent color (#0066FF) version for glow moments

## Motion Principles

1. **Reveal over entrance** — Elements should feel like they're being uncovered, not flying in
2. **Glow before text** — Lead with the blue glow/gradient, then text fades in on top
3. **Hold moments** — Let key lines sit for 1–2s before the next beat. Don't rush.
4. **Mono labels first** — Eyebrow labels (JetBrains Mono) appear before the main headline
5. **Stats count up** — Any metric (40+ hrs, 98%, 300+) should animate counting upward
6. **Easing** — Ease-out curves. Nothing linear. Decelerate into rest positions.
7. **Transitions** — Fade through black OR directional wipes left-to-right. No slide-ins from edges.

## Scene Structure Template (30s format)

```
00:00 – 00:03   Black. Ψ symbol fades in with blue glow. Holds.
00:03 – 00:06   "DUALITY LABS" wordmark materializes below Ψ
00:06 – 00:10   Cut to black. Eyebrow: "AI AUTOMATION" → headline fades in
00:10 – 00:14   Stat reveal: "40+ hrs/week" counts up
00:14 – 00:18   Scene: floating UI/dashboard element (blurred, glowing)
00:18 – 00:22   Headline: "We build the systems your business runs on."
00:22 – 00:26   Quick cut montage: 3 service labels in mono type
00:26 – 00:30   Logo lockup + CTA: "dualitylabs.ai"
```

## Jitter Notes

- Work at **1920×1080** (16:9) for hero/website use OR **1080×1080** for social
- Frame rate: **24fps** for cinematic feel
- Export: MP4 (H.264) for web, WebM for site embedding
- Keep a Figma source file with all static frames before animating in Jitter
